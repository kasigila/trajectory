# Trajectory

Local studio for dated body-weight scenarios. Data stays in this browser (`localStorage`). There is no hosted account and no health-platform sync.

The forecast is the published Hall dynamic adult model (`hall-lancet-2011`, webappendix to Hall et al., Lancet 2011;378:826–837). It is not a clinically validated medical device and not medical advice.

```bash
npm install
npm test
npm run dev
```

The dev server listens on `0.0.0.0:5173`. Open http://127.0.0.1:5173 . Confirm you are 18 or older, then the sample profile (Alex Rivera) shows the trajectory chart first.
